## 0.1.0-dev.1

- Add the initial typed Android and iOS Flutter plugin contract.
- Add immutable lifecycle snapshots and separate state and event streams.
- Add explicit permission, restoration, battery optimization, tracking,
  analysis, report, session, and logging APIs.
- Restore iOS tracking state from the native manager status and align the
  example CocoaPods deployment target with the plugin's iOS 15 minimum.
- Add Pigeon-generated Kotlin and Swift transport contracts.
- Add an example application, contract tests, architecture records, and
  compatibility documentation.
- Add GitHub Actions validation and short-lived internal example artifacts.
- Add release-candidate validation, generated release notes, dependency
  freshness reporting, and explicitly gated pub.dev OIDC publishing.
- Document public pub.dev and private Git or hosted-registry distribution
  paths.

This version is a non-publishable local development draft. Native artifact
access, package ownership, license, and final compatibility policy remain
release blockers.
